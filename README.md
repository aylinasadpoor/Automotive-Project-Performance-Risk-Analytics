# Automotive Project Performance & Risk Analytics Dashboard

**Portfolio Project 03 of 05 | Power BI | Project Controls & Data Analytics**

## Project Overview

This project presents a Power BI dashboard for monitoring an automotive production line expansion scenario. It combines project activity tracking, cost and schedule performance analysis, Earned Value Management (EVM), and project risk monitoring.

The dashboard is designed to transform project information into visual reports that support performance reviews and project-control decisions.

## Dashboard Pages

### 1. Project Management Dashboard
- Total activity count and average progress
- Activity status distribution
- Activity-level schedule and cost information
- Budget versus actual cost by WBS

### 2. Cost & EVM Analysis
- Budget at Completion (BAC)
- Planned Value (PV), Earned Value (EV), and Actual Cost (AC)
- Cost Variance (CV) and Schedule Variance (SV)
- Cost Performance Index (CPI) and Schedule Performance Index (SPI)
- Estimate at Completion (EAC) and Variance at Completion (VAC)
- Weekly performance trends

### 3. Project Risk Analysis
- Risk count and risk categories
- Probability-impact risk scores
- Risk status distribution
- Risk register and mitigation actions
- Identification of high-priority risks

### 4. Executive Summary
- Consolidated EVM indicators
- Weekly project performance overview
- Project status indicators
- Key project-control focus areas

## Key Performance Indicators

| KPI | Definition |
|---|---|
| BAC | Budget at Completion |
| PV | Planned Value |
| EV | Earned Value |
| AC | Actual Cost |
| CV | EV − AC |
| SV | EV − PV |
| CPI | EV / AC |
| SPI | EV / PV |
| EAC | Estimate at Completion |
| VAC | Variance at Completion |
